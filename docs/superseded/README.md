# Superseded prose specification

These two documents were the original hand-written specification. They are
**fully superseded** by `checkers-core` and the generated
`specs/specification.md`, and are no longer authoritative.

All fifteen chapters now have registered laws, so every normative claim these
files made is machine-checked. They are retained only as a historical record of
where the specification came from, and can be deleted at any time.

Do not cite these files from code. Cite law IDs.
